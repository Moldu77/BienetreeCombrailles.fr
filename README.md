## 🇫🇷 Présentation

**Bien-être en Combrailles** est un site vitrine destiné à présenter les prestations d’aide à domicile, d’accompagnement et de soutien proposées dans les Combrailles.

Le site est entièrement statique (HTML + CSS) et optimisé pour un hébergement via **GitHub Pages**.  
Il inclut un formulaire de contact fonctionnel grâce à **Formspree**.

---

## 📁 Structure du projet

/
├── index.html # Page d’accueil
├── contact.html # Formulaire de contact
├── styles.css # Styles du site
├── images/ # Ressources visuelles
└── README.md # Documentation

---

## 🚀 Déploiement via GitHub Pages

1. Ouvrir **Settings**
2. Aller dans **Pages**
3. Sélectionner la branche : `main`
4. Dossier : `/root`
5. Enregistrer

GitHub génère automatiquement l’URL publique du site.

A functional contact form is integrated using **Formspree**.

├── contact.html # Contact form

## 🚀 Deployment with GitHub Pages

1. Open **Settings**
2. Go to **Pages**
3. Select branch: `main`
4. Folder: `/root`
5. Save

GitHub will automatically generate the public website URL.
